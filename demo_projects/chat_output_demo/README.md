# Chat Output Demo

This is a tiny Python project used to verify the Yuanbao chat output surface.
It is intentionally small so the frontend can show the whole agent loop:

- inspect project files
- read source and tests
- run a command
- summarize findings without editing files

## Suggested Prompt

Please inspect this demo project, read the source and tests, run:

```powershell
python -m pytest tests -q
```

Do not modify files. In the final answer, summarize the project structure,
the command result, and one possible next improvement.
